# SHOP-31

SHOP-31 Checkout and orders. POST /carts/:id/checkout turns a cart into an order: it reserves stock for every item (all or nothing: if any item lacks stock, nothing is reserved and it answers 409 OUT_OF_STOCK with the product ids), charges a payment through a PaymentGateway port (a fake in-memory gateway for now, which declines card tokens starting with 'tok_declined'), stores the order with status 'paid', and empties the cart. On payment failure, release the reserved stock and answer 402 PAYMENT_DECLINED. Orders: GET /orders/:id, GET /orders?status=paid|shipped|cancelled, POST /orders/:id/ship (only paid orders), POST /orders/:id/cancel (paid orders only; refunds through the gateway and returns stock). Each order keeps the item prices at checkout time, the totals, the payment id and a status history with timestamps.
